BOUTIQUE FACILE - SOURCES (version 6)

Fabriquer l'application :
  python3 build.py
Le résultat arrive dans le dossier dist/ :
  index.html, sw.js, manifest.webmanifest et les icônes = les fichiers à mettre sur GitHub.
  decouvrir.html (présentation), guide.html (guide d'utilisation) et le dossier captures/ aussi.
  artifact.html = la version d'essai en ligne (cadre isolé).

Dossiers :
  src/     le code de l'application (src/js = les écrans, src/app.css = le design)
  assets/  les icônes et le dessin du logo (mklogo.py)
  logo/    les scripts qui fabriquent le kit du logo et la charte
  pages/   la page de présentation et le guide (site.css = leurs couleurs, captures/ = images)
  tests/   les tests automatiques (Playwright) : runall.sh les lance tous
           captures.js refait les captures d'écran du guide (boutique d'exemple fictive)

Important : le logo est dessiné par du code (mklogo.py). Ne le redessinez pas à la main.
