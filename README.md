# Boutique Facile

Application de caisse, stock, dettes clients et comptabilité pour petites boutiques et pharmacies. Fonctionne sans internet, les données restent sur le téléphone.

Ouvrir l'application : https://devotionobstine-dev.github.io/Boutique-Facile/

Pour l'installer sur iPhone : ouvrir le lien dans Safari, puis Partager, puis « Sur l'écran d'accueil ».
Sur Android : ouvrir le lien dans Chrome, puis « Installer l'application ».
